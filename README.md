# Промспецбуд-Інвест

Сайт ТОВ «Промспецбуд-Інвест» (Кривий Ріг): оренда спецтехніки та обладнання, будівельно-монтажні роботи, склади в оренду. Три мови: українська, російська, англійська.

Статичний сайт для GitHub Pages: `index.html`, фото в `ph/` та `img/`. Авторство фото вказано на сайті в блоці «Авторство фото».
